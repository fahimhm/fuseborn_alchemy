# Hero Pool: Races & Classes

Reference for creating new heroes. A hero is **Race – Class** with one **Role** (GDD §15.1). Entries marked ✔ are already used in the roster (GDD §15.2–15.4).

## Naming Rules
1. A class is **never a role word** (Tank, Warrior, Ranger, Assassin, Mage, Support) and avoids near-role words (Healer, Buffer).
2. **Each class name is used once** across the roster.
3. A compound race only when it's a known type (Dark Elf, Wood Elf, Half-Angel), not a mash-up (no "Goblin Zombie").
4. Race drives the **look**; class drives the **weapon and flavor**; role drives **combat behavior**.

Grouping races into families keeps art efficient: races in one family can share a base body and rig (see GDD §6.1 art note).
